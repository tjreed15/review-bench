# Code of Conduct

## Our pledge

ReviewBench is committed to providing a welcoming, harassment-free experience for everyone who participates in the project — contributors, maintainers, and users alike — regardless of background, identity, or experience level.

## Our standard

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. All participants in ReviewBench spaces — issues, pull requests, discussions, code review comments, and any associated communication channels — are expected to follow it.

The full text is canonical at:

> <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

A plain-text version is also available at:

> <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt>

If you contribute to ReviewBench, you agree to abide by it.

## Scope

This Code of Conduct applies to all project spaces — the GitHub repository (issues, PRs, discussions, code review), any official communication channels, and to anyone representing the project in public spaces (e.g. presenting ReviewBench at a conference, posting about it under an official handle).

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it to the maintainers privately. We take all reports seriously and will respond promptly.

**How to report:**

- **Preferred:** open a private report via **GitHub Private Vulnerability Reporting** at <https://github.com/researchbites/review-bench/security/advisories/new>. Although the form is labeled "security advisory," it is the only built-in private channel GitHub provides for a public repo, and it routes directly to maintainers without exposing the report publicly. Title your report `[Code of Conduct]` so we can triage it appropriately.
- **Alternative:** mention `@researchbites/maintainers` in a private context (e.g. a direct message to a maintainer) — do **not** post the report in a public issue, PR, or discussion.

When reporting, please include:

- What happened, with as much detail as you're comfortable sharing
- Where it happened (link to the issue / PR / comment if applicable)
- Who was involved
- Any supporting context (screenshots, links)
- Whether you'd like to remain anonymous in any follow-up communication

## Enforcement

Maintainers are responsible for clarifying and enforcing this Code of Conduct. They will respond to every report received in a fair and timely manner.

Maintainers follow the **Contributor Covenant Enforcement Guidelines** (linked from the Covenant document above) when deciding consequences for violations. Possible responses include, in escalating order:

1. A private written warning with clarification of the violation
2. A public warning
3. A temporary ban from project spaces
4. A permanent ban from project spaces

Maintainers who fail to enforce this Code of Conduct in good faith may face temporary or permanent repercussions as determined by other maintainers.

## Confidentiality

Reports will be handled with discretion. Reporter identities will not be shared beyond the maintainers handling the report without the reporter's explicit consent, except where required by law.
